# Dados

Pasta de dados brutos e consolidados (Premissa 5 - rastreabilidade dos dados).

- `gestao/` - medições de acompanhamento do projeto (Premissa 3).
- `avaliacao/` - dados de coleta das métricas do VICKY, organizados por ID de métrica (ex.: `avaliacao/M1.1.1/`).

Dados de participantes devem ser anonimizados (ex.: P01, P02) antes de entrar no repositório.
