# Premissa 2 - Definição das métricas (GQM)

> Utilizar o método Goal-Question-Metric (GQM) para estabelecer a ligação entre objetivos, questões e métricas. Para cada métrica, documentar a definição, o procedimento de cálculo, a fonte dos dados, o procedimento de coleta e os critérios de interpretação.

## Níveis do GQM

| Nível | Elemento | Pergunta-guia |
|-------|----------|---------------|
| Conceitual | Objetivo (G) | O que queremos avaliar, com que propósito e do ponto de vista de quem? |
| Operacional | Questão (Q) e hipótese (H) | O que precisamos responder para saber se o objetivo foi atingido, e o que esperamos encontrar? |
| Quantitativo | Métrica (M) | Que dado objetivo responde a cada questão? |
